# Compile/Merge Compliancelists

Compile exported Intune reports for Noncompliant devices into a formated excel spreadsheet or merge 2 lists with each other, to update the data.

## Requirements

### Python libraries

- [pandas](https://pypi.org/project/pandas/)
- [openpyxl](https://pypi.org/project/openpyxl/)
- [validators](https://pypi.org/project/validators/)

## Usage/Compiling

### CLI arguments

- `'-i'/'--InputFile'`: The path of the input file to process. Must be a .csv file (Mandatory)
- `'-o'/'--OutputFile'`: The path of the output file. If not set, the name of the input file will be used instead
- `'-w'/'--WantedOS'`: The OS you want to compile the data for. Default is 'Windows'
- `'-d'/'--DeviceLinkSkip'`: Skip the creation of the device overview links
- `'-e'/'--EmailLinks'`: Convert Emails into teams chat links
- `'-k'/'--KeepDeviceIds'`: Keep the Device Id column
- `'-h'/'--Help'`: Show this help and exit the program

## Usage/Merging

### CLI arguments

- `'-o'/'--OldFile'`: The path of the input file of the old data to merge. Must be a .xlsx file (Mandatory)
- `'-n'/'--NewFile'`: The path of the input file of the new data to merge. Must be a .xlsx file (Mandatory)
- `'-m'/'--MergedFile'`: The path of the output file. If not set, the name will be generated by this pattern: 
    '[old file name (with path)]-[new file name (without path)]_merged.xlsx'
- `'-w'/'--WantedOS'`: [Not yet implemented] The OS you want to merge the data for. Default is 'Windows'
- `'-c'/'--CompileCSV'`: [Not yet implemented] Try to automatically compile .csv files if given as input
- `'-d'/'--DeviceLinkSkip'`: Skip the creation of the device overview links
- `'-e'/'--EmailLinks'`: Convert Email into teams chat links
- `'-k'/'--keepDeviceIds'`: Keep the Device Id column
- `'-h'/'--Help'`: Show this help and exit the program
